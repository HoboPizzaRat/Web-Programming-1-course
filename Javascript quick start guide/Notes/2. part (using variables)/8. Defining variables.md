
# global
without giving a variable a proper type we make them global
- bad for bigger scope projects, might accidentally reuse the same variable name and overwrite existing variables

```javascript
globalVariable = 10;
```
## const 
variable with type const makes it immutable
- meaning we cannot change it after the instantiation
- though in lists we can affect the values within it

```javascript
const constantVariable = 10;
```

## let and var
dont use vars, it is old javascript and its always hoisted into the top scope
- might create conflicts
Let variable declaration makes the variable be contained in the inner most scope
- variables defined with let are mutable and can be changed during during the program execution
```javascript
let variable = 10;
variable = 20;
console.log(variable);
```
