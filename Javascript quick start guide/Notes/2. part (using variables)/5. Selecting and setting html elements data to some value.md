
There are 3 different kinds of ways to access elements roughly

### querySelector()
this method returns the first element found in the DOM
- if you want to access element with id, you must precede the parameter with "#"
```javascript
let greetingElem = document.querySelector("#greeting");
```

### getElementById()
there can be only one element with given id on the document, used to capture only one element with given id
```javascript
let greetingElem = document.getElementById("greeting");
```

### querySelectorAll()
can be used to select multiple elements from 
```javascript
let greetingCards = document.querySelectorAll(".greetingCard");
```


# setting variables into values

### elem.textContent
can be used to set the text content into element
```javascript
let greetingCards = document.querySelectorAll(".greetingCard");

for(let card of greetingCards){
	card.textContent = "Hello from a card";
}
```

### elem.innerHTML
can be used to embed html directly inside the element
- can be dangerous and result to front end vulnerabilities
```javascript
let greeting = document.getElementById("greeting");
greeting.innerHTML = `
	<div class="greetignCArd">
		<p>Hello there, general kenobi</p>
	</div>
`;
```
