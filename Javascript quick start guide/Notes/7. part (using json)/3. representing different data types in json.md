json objects basically follow the same variable type conversion as in javascript in general


so booleans are like so:
```json
{"name": "Mohit Kumar",  "isStudent": false}
```

and numbers like so:
```json
{"name": "Mohit", "age": 30}
```


here is the whole list of different data types supported by json

- ****String:**** A sequence of characters, e.g., "hello".
- ****Number:**** Integer or floating-point numbers, e.g., 10, 3.14.
- ****Boolean:**** A value representing true or false.
- ****Array:**** An ordered list of values.
- ****Object:**** A collection of key-value pairs.
- ****Null:**** A null value indicating the absence of any value
