# Controlling Animations

## Web Animations API

Use `Element.animate()` to create and control animations.

```js
const animation = element.animate(
  [
    { transform: "translateX(0)" },
    { transform: "translateX(200px)" }
  ],
  {
    duration: 1000,
    iterations: Infinity
  }
);

animation.play();      // start / resume
animation.pause();     // pause
animation.cancel();    // cancel and reset
animation.finish();    // jump to the end
animation.reverse();   // reverse direction

animation.playState

animation.playbackRate = 2;   // 2× speed
animation.playbackRate = 0.5; // 0.5× speed
```
