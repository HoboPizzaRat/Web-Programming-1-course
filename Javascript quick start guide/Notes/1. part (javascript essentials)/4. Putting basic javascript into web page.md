By putting script tage we can embed javascript directly into html file
```html
<!DOCTYPE html>

<html lang="en">
<head>
	<meta charset="UTF-8">
	<meta name="viewport" content="width=device-width, initial-scale=1.0">
	<meta http-equiv="X-UA-Compatible" content="ie=edge">
	<title>Hello, World!</title>
</head>
<body>
	<p>
	<script>
		document.write("Hello, World!");
	</script>
	</p>
</body>
</html>
```


we can also do the following
```html
<script src="./somefilelocation.js"></script>
```
the following way we can embed external js file into the web page
