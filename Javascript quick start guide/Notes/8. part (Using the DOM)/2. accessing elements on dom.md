## document.getElementsByTagName()

```javascript
let pTags = getElementsByTagName("p")

//we can access all the tags by using indexing
let firstP = pTags[0];
firstP.textContent = "Olen ensimmäinen paragraph";
```

## document.getElementsByClassName()
selects elements by the specified class
```javascript
let classList = getElementsByClassName("helloClass")

//we can access all the tags by using indexing
let first = classList[0];
first.textContent = "Olen ensimmäinen paragraph";
```
