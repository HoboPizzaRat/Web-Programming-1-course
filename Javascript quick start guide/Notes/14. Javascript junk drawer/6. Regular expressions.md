Regular expressions (**regex**) are patterns used to **search, match, extract, and replace text**.

## Creating a Regex

### Literal syntax

```js
const regex = /hello/;
```

### Constructor

```js
const regex = new RegExp("hello");
```

Literal syntax is usually preferred.

---

# Basic Patterns

|Pattern|Meaning|
|---|---|
|`abc`|Matches `"abc"`|
|`.`|Any character except line terminators|
|`\d`|Digit `[0-9]`|
|`\D`|Non-digit|
|`\w`|Word character `[A-Za-z0-9_]`|
|`\W`|Non-word character|
|`\s`|Whitespace|
|`\S`|Non-whitespace|
|`\b`|Word boundary|
|`^`|Start of string|
|`$`|End of string|

Example:

```js
/\d\d\d/
```

Matches:

```text
123
```

---

# Character Classes

```js
/[abc]/
```

Matches **one** of `a`, `b`, or `c`.

```js
/[a-z]/
```

Any lowercase letter.

```js
/[A-Z]/
```

Any uppercase letter.

```js
/[0-9]/
```

Any digit.

### Negated class

```js
/[^0-9]/
```

Matches anything that is **not** a digit.

---

# Quantifiers

|Quantifier|Meaning|
|---|---|
|`*`|0 or more|
|`+`|1 or more|
|`?`|0 or 1|
|`{n}`|Exactly `n`|
|`{n,}`|At least `n`|
|`{n,m}`|Between `n` and `m`|

Examples:

```js
/\d+/       // one or more digits
/\d{3}/     // exactly 3 digits
/[a-z]{2,5}/ // 2–5 letters
```

---

# Groups

Parentheses create a **capturing group**:

```js
/(hello) (world)/
```

Captures:

```text
hello
world
```

Non-capturing group:

```js
/(?:hello|goodbye)/
```

---

# Alternation

`|` means **OR**.

```js
/cat|dog/
```

Matches either:

```text
cat
dog
```

# Regex Methods

## `test()`

Returns `true` or `false`.

```js
const regex = /\d+/;

regex.test("Age: 25");
// true
```

## `match()`

Returns matches from a string.

```js
"hello 123".match(/\d+/);
// ["123"]
```

## `search()`

Returns the index of the first match.

```js
"hello 123".search(/\d+/);
// 6
```

## `replace()`

Replace matched text.

```js
"hello world".replace(/world/, "JavaScript");
// "hello JavaScript"
```

# Flags

Flags modify how the regex behaves.

```js
/hello/g
```

|Flag|Meaning|
|---|---|
|`g`|Global — find all matches|
|`i`|Case-insensitive|
|`m`|Multiline|
|`s`|`.` also matches line terminators|
|`u`|Unicode mode|
|`y`|Sticky matching|
|`d`|Include match indices|

Example:

```js
/hello/gi
```

Matches:

```text
hello
HELLO
Hello
```

---

# `g` Example

Without `g`:

```js
"cat cat cat".match(/cat/);
// ["cat"]
```

With `g`:

```js
"cat cat cat".match(/cat/g);
// ["cat", "cat", "cat"]
```

---

# Escaping

Special regex characters can be escaped with `\`.

```js
/\./
```

Matches a literal `.`.

Common special characters:

```text
.  *  +  ?  ^  $  { }  ( )  [ ]  \
```

Example:

```js
/\$10/
```

Matches:

```text
$10
```

# Useful Examples

### Only digits

```js
/^\d+$/
```

### Simple email pattern

```js
/^[^\s@]+@[^\s@]+\.[^\s@]+$/
```

### Starts with `hello`

```js
/^hello/
```

### Ends with `.js`

```js
/\.js$/
```

### Find all words

```js
/\b\w+\b/g
```

---

# Greedy vs Lazy

Quantifiers are **greedy** by default:

```js
/<.*>/
```

Attempts to match as much as possible.

Add `?` to make it **lazy**:

```js
/<.*?>/
```

Matches as little as possible.

For:

```text
<b>Hello</b>
```

`/<.*>/` can match the entire string.

`/<.*?>/` matches:

```text
<b>
```

# Quick Mental Model

```text
/ pattern / flags
    │        │
    │        └── How matching behaves
    └────────── What to match
```

Example:

```js
/^\d{3}$/g
```

Means:

```text
^       start
\d      digit
{3}     exactly 3 times
$       end
g       global
```

So it matches a string consisting of exactly **three digits**.
