Sets is a collection type where you cannot add more than one time of each item.
- basically contains only unique values
- you can try to add 2 times the same object or data into it but it will only add it into it only once


basic methods of the set
```javascript
const set = new Set();

set.add("apple");       // add value
set.add("banana");

set.delete("apple");    // remove value

set.has("banana");      // true

set.clear();            // remove everything

set.size;               // number of values
```


converting list to sets and wise versa
```javascript
const arr = [1, 2, 2, 3, 3];

const set = new Set(arr);
// Set { 1, 2, 3 }

const arr = [...set];
```
