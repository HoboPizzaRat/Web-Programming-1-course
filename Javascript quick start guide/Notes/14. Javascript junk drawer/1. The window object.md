This was less talked about topic. 

Its basically the way to talk to the browser itself
- all console methods talk to the window object and browser


## window.history
it is a way to navigate forwards and backwards on history session in the browser
```javascript
history.forward()
history.back()
```


## window.location
It's a really useful browser API for working with the **current URL** and navigating to other URLs.

|Property|Example value|
|---|---|
|`location.href`|`"https://example.com/products?id=42#reviews"`|
|`location.protocol`|`"https:"`|
|`location.host`|`"example.com"`|
|`location.hostname`|`"example.com"`|
|`location.port`|`""`|
|`location.pathname`|`"/products"`|
|`location.search`|`"?id=42"`|
|`location.hash`|`"#reviews"`|
|`location.origin`|`"https://example.com"`|

## window.navigator
It gives you information about the **browser and the user's environment**, and provides some browser-related APIs.

|Property|Description|
|---|---|
|`navigator.userAgent`|Browser's user-agent string|
|`navigator.language`|User's preferred language|
|`navigator.languages`|Preferred languages|
|`navigator.platform`|Platform information|
|`navigator.onLine`|Whether browser reports being online|
|`navigator.cookieEnabled`|Whether cookies are enabled|
