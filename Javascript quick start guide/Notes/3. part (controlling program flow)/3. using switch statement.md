switch statements are not present in python, but the idea is simple

```javascript
let color = "blue"
switch (color) {
	case "red":
		console.log("The color is red.")
		break
	case "orange":
		console.log("The color is orange.")
		break
	case "purple":
		console.log("The color is purple.")
		break
	default:
		console.log("I'm not sure what color it is.")
}
```

Do take a note that if you don't use the break command the execution falls through the switch statement and all the consecutive statements gets executed after the first value that passes the truth test
