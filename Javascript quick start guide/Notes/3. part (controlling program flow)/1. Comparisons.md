## == vs ===
in javascript many bugs might occur when using the == operator since
- it converts the values into same type and then does the comparison
- meaning you can compare string "2" and number 2 and it will result to true
Preferrably use === operator whenever possible
- it results to true if the both operands are same type and the values are the same
