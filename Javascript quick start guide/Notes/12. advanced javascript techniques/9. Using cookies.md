## creating a cookie
```javascript
document.cookie = "key=value"
```


## reading a cookie
```javascript
function getCookie(name) {
	// Add the equal sign to the name (name=)
	let cookieName = name + "="
	// Decode cookie string to handle cookies with special characters
	let decodedCookie = decodeURIComponent(document.cookie)
	// Check if there are any cookies to process
	if (!decodedCookie) {
		return null
	}
	// Split document.cookie on semicolons into an array
	let cookieArray = decodedCookie.split(";")

	// Iterate through the name=value pairs in the cookieArray
	for (let i = 0; i < cookieArray.length; i++) {
	
		let cookie = cookieArray[i]
	
		// Remove any leading spaces using a regular expression
		cookie = cookie.replace(/^\s+/, "")
	
		// If cookie is found, return its value
		if (cookie.indexOf(cookieName) === 0) {
			return cookie.substring(cookieName.length, cookie.length)
		}
	}
	// If cookie name was not found, return null
	return null

}
```
take a note that in this function you need to specify as the first parameter the cookie name you want to retrieve.
- then you take the cookie name and add = sign to it
- then you take the whole cookie list using the decodeURIComponent and document.cookie
- if there are no cookies in decodedCookie, we return empty
- in other case when there is something in decodedCookie, we split them into array
- then we iterate through every cookie in the array
	- we check the cookie, if its the same as the requested cookie, we return the value
- if the cookie is not found by name, we return null


## updating a cookie
```javascript
document.cookie ="oldkey=newValue";
```
take a note that in this case we dont rewrite the whole sites cookies to be the new key-value pair. It behaves very weirdly and just appends that to the dataset of cookies


## expiring cookies
we can set a expiration date for cookies like so:
```javascript
document.cookie = "username=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/;";
```
jus by simply setting the value to the past we can expire a cookie instantly

more modern way to expire a cookie is this
```javascript
document.cookie = "username=; max-age=0; path=/;";
```


if we want to make so that the cookie exprires in some future we can do
```javascript
const date = new Date(); 
date.setDate(date.getDate() + 3); 
document.cookie = `username=Jalo; expires=${date.toUTCString()}; path=/`;
```
