
## slice
you can slice a copy of a string using this method
- enables copying the whole string, useful for functional programming

```javascript
let result = "string is here".slice(startIndex, endIndex);
console.log(result);
```


## toLowerCase() and toUpperCase()
converts the strings into uppercase or lowercase depending which one you use


## length property
you can get the length of the string or array using this inbuilt property


## split
you can use it to split string into array of items using the proper splitter or delimitter
```javascript
let arr = "something to split".split(" ");
for(let item of arr){
	console.log(item);
}
```


## replace
you can replace string items with other elements with this method.
Without using regex and by only providing single string it will only replace the first occurence of the given substring from the string.
- you can also provide a regex into this method, by usign global flag you can replace all occurences
- this method is case sensitive until otherwise specified by the i flag
```javascript
let replaced = "something to replace".replace("something", "mörkö");
console.log(replaced);

```


## trim
the trim method removes the white spaces outta strings end and start
- there are trimend and trimstart methods for both start and end of string trimming
