```javascript
let parameter = "kekkonen"
const func = (parameter) => console.log(parameter);
func();
```
though if you are returning values from the function you can do it the following manner

either this
```javascript
let parameter = "kekkonen"
const func = (parameter) => `moi ${parameter}`;
console.log(func());
```

or this
```javascript
let parameter = "kekkonen"
const func = (parameter) => {
	return `moi ${parameter}`;
}
console.log(func());
```

if you need more than 1 line for your arrow function just use the {} convention and return clause
