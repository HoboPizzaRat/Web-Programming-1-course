A JavaScript Promise is an object that represents the eventual completion or failure of an asynchronous operation and its resulting value. It can be in one of three states: pending, fulfilled, or rejected


how to create promises
```javascript
const promise = new Promise((resolve, reject) => {
    // do something...

    resolve("Success!");
});
```

async function getUser() {

    } catch (error) {

    }
}
