we can make thing run periodically, like update functions, just by simply using setInterval function.

```javascript
let tickCount = 0

function incrementTicks() {
	tickCount += 1
	console.log(`There have been ${tickCount} ticks so far.`)

}

const interval = setInterval(incrementTicks, 1000)
```

the following incrementTicks function runs every second. 


We can delete the intervals by running a clearInterval function and providing the function the method whose setinterval gets cancelled.

like so
```javascript
clearInterval(interval);
```

this is why its important to set the setInterval functions returning object into a variable
