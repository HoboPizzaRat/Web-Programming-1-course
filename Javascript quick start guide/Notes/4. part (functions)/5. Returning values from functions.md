The returning values from functions is done by return keyword

If you do not provide a default value to a return keyword or do not use return keyword at the end of an function, the value "undefined" is returned

javascript function cannot return multiple values(unlike python), though you can combine multiple values into one object for example and return that

```javascript
function returningFunction(arg="kakkonen"){
	return `Kekkonen-${arg}`
}

console.log(returningFunction()) //prints kekkonen-kakkonen
```
