In javascript we can define objects without the class keyword

```javascript
let menu = {
	inventory: {
		"Regular Coffee": 3.00,	
		"Espresso": 3.50,		
		"Cappuccino": 4.00,		
		"Latte": 4.25	
	},
	populate: function(container) {
	
		for (let item in this.inventory) {
		
		let price = this.inventory[item]
		
		container.innerHTML += "<li>" + item + " - $" + price.toFixed(2) + "</li>"
		}
	}
}
```

we can define these empty objects basically everythign that the js classses have, functions, etc.

Im not sure but i think that there cannot be constructors on objects created like this
