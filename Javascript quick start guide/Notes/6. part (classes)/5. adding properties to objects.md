lets say we have an empty object
```javascript
let obj = {};
```

we can add them properties by simply addressing them like this
the objects properties names are also called keys
in the below example the objects key is called someproperty

```javascript
obj.someproperty = 20;
```

we can also add properties with spaces to the objects like this

```javascript
obj.["some property"] = 20;
```

we can also use other variables values as the objects keys
```javascript
let var1 = "kekkonen";
obj[var1] = 300

// we can now access the "kekkonen" key by addressing
console.log(obj["kekkonen"]) //prints: 300
```
