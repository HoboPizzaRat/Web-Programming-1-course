we can create custom iteration schema to every object on javascript by creating function on key called "Symbol.iterator"

example
```javascript
evenNumbers = {}

evenNumbers[Symbol.iterator] = function() {
	let n = 0
	return {
		next() {
			n += 2
			return {value: n, done: false}
	}
}
```

then we can iterate through given iterator range by simply using the given loop

```javascript
for (let n of evenNumbers) {
	console.log(n)
	if (n >= 10) break
}
```
